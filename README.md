# 🎲 Tavla

Tarayıcıda çalışan klasik Türk tavlası. Kurulum gerekmez; bilgisayarda ve telefonda çalışır.

**▶ Oyna:** https://sahsenemozer.github.io/tavla/

## Özellikler

- **Bilgisayara karşı** (Kolay / Orta / Zor) ve **iki kişilik** (aynı cihazda) mod
- 1, 3, 5 veya 7 puanlık maçlar
- Türk tavlası kuralları: kırma, bar, toplama, **mars** (2 puan); zorunlu zar kuralları
- Dokun-seç veya sürükle-bırak; iki zarı tek pulla tek dokunuşta oynama; hamle geri alma
- Animasyonlar, sesler, mobilde titreşim
- Telefon dikken tahta otomatik döner ve ekranı doldurur
- Oyun otomatik kaydedilir, kaldığın yerden devam edilir
- Ana ekrana eklenebilir (PWA) ve internetsiz de açılır

## Telefona uygulama gibi kurmak

- **Android (Chrome):** Siteyi aç → menü (⋮) → *Ana ekrana ekle* / *Uygulamayı yükle*
- **iPhone (Safari):** Siteyi aç → Paylaş → *Ana Ekrana Ekle*

## Klavye kısayolları

| Tuş | İşlev |
| --- | --- |
| Boşluk / Enter | Zar at / hamleyi onayla |
| Z / Backspace | Geri al |
| Esc | Seçimi kaldır |
